# backimg v1.3.20 变更清单 —— 随机功能重做（A 真随机源 / B 按窗口记账 / C 定时轮换）

- **发布日期**：2026-10-28
- **基线**：v1.3.19（桌面原样保留，未改动）
- **触发**：用户反馈"总觉得不太随机"。核验确认三个真实成因，全部修复；
  并按用户需求新增定时轮换功能（GUI 面板可视化配置）。

---

## 一、成因核验（改了什么、为什么）

| 编号 | 成因 | 处置 |
|---|---|---|
| A | `rand()` + `srand(time(0))`：种子只精确到秒——explorer 秒级重启会拿到同一种子，整条"随机"序列逐字复现；rand() 本身是低质量线性同余生成器，连续取值相关性强，且非线程安全 | ✅ 新增 `RandomIndex()`（WinAPI.cpp）：mt19937 梅森旋转 + 随机设备/系统计数/ASLR 地址三路混种，`uniform_int_distribution` 消除模偏差，互斥锁串行化（调用频率极低，无竞争） |
| B | `t_myData` 每线程单槽：Win10/11 多标签资源管理器共用一条 UI 线程，同线程开第二个标签，新记录直接顶掉旧记录——两个标签画同一张图 | ✅ 改全局登记表 `g_wndData`（键=窗口句柄，`g_wndDataMx` 保护）；绘制会话用 thread_local `t_sessionHwnd` 串联；两把锁（g_wndDataMx/g_listMx）任何路径不嵌套持有，无死锁面 |
| C | 一窗一签、抽完焊死：随机只在窗口诞生瞬间发生一次，窗口活着图永远不换 | ✅ 新增定时轮换：登记窗口挂 Windows 窗口定时器，到点重抽签 + InvalidateRect 重绘；间隔由面板配置，落盘 `randomMin`（整数分钟） |

## 二、C 定时轮换设计细节

- **配置**：`config.ini → [image] randomMin`，**单位就是分钟本身**（用户明确要求：
  不吃小数、不做换算），0 = 不轮换（默认，兼容老配置），上限 1440（一天）。
- **面板控件**：random 行右侧"定时轮换"自绘下拉（与「界面缩放」同源画法，
  当前档打勾）＋"自定义…"整数分钟输入框（内层 EDIT 挂 `ES_NUMBER`，
  小数点从输入源头就输不进去）。随机显示关闭时整组置灰。
- **档位**：不轮换 / 每 1 分钟 / 每 2 分钟 / 每 5 分钟 / 每 10 分钟 / 每 30 分钟 / 自定义…
- **非法值兜底**（config.ini 按不可信输入处理，与 v1.3.18 的 SafeToInt 同一纪律）：
  负数/缺键 → 0（不轮换）；>1440 → 1440；自定义态输入框只可能是数字。
- **定时器机制**：
  1) TimerProc 跑在窗口属主线程（窗口定时器 WM_TIMER 投递到窗口消息队列），重抽签/重绘天然同线程；
  2) 回调自纠错：每次都读当前配置——随机关/间隔清零自动自拆定时器，间隔改了按新周期重设；
  3) `LoadSettings` 读到配置变化后 `ApplyRotateTimerAll()` 对全体登记窗口统一重装
     （带 hWnd 的 SetTimer/KillTimer 挂在目标窗口自己的消息队列上，跨线程调用安全）；
  4) 只有一张图（<2）时到点不换；图片列表整体换掉后下标有越界钳位兜底（v1.3.16 机制沿用）；
  5) 回调整体 try/catch——任何异常就地吞掉，绝不送进 explorer 的消息循环。

## 三、B 重构涉及的所有触点

| 函数 | 改动 |
|---|---|
| `MyCreateWindowExW` | 登记进 `g_wndData[hWnd]`（不再按线程覆盖）；抽签用 RandomIndex；登记后按当前配置装轮换定时器 |
| `MyDestroyWindow` | 按窗口句柄注销；显式 KillTimer（幂等）；会话标记/深度清零条件从"本线程记录匹配"改为"本窗口注销成功" |
| `MyBeginPaint` | 按句柄查表开启会话；只在"无进行中会话或就是当前会话窗口（重入）"时开启，语义与旧版一致 |
| `MyEndPaint` | 会话深度归零时归还 `t_sessionHwnd` |
| `MyFillRect` | 先取登记表标量快照（hWnd/ImgIndex）再干活；尺寸记账、越界钳位结果均写回登记表；锁内只做查找与标量拷贝 |
| `MyCreateCompatibleDC` | 按会话窗口查表替换记录的 DC |
| `LoadSettings` | 解析 randomMin（钳位）；变更后 ApplyRotateTimerAll |
| `InjectionEntryPoint` | 拆除 srand（随机源自带播种） |

## 六、使用者须知

- 装完默认行为与 v1.3.19 完全一致（randomMin 缺省 0 = 不轮换）——想开定时换图，
  面板 random 行右侧选档位或填自定义分钟，**保存配置 → 重启资源管理器**。
- 多标签/多窗口现在**各自独立抽签**，互不覆盖（本版之前会互相顶掉）。
- 定时轮换是"每窗口各自换图"，到点每个文件夹窗口独立重抽，不是全体同步换同一张。
- explorer 实机表现（随机手感、定时换图、多标签独立）需安装后由用户实测确认。
