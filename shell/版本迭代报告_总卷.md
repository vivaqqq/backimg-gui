### v1.3.13 — 拖影根因修复 + 核验观察点 3 项
依据用户实机标注（红框=滑块鬼影、蓝框=摘要乱字）+ 豆包《v1.3.12 核验报告》3 个观察点：
- **滑块拖影（根因级）**：`backimgSlider` 的 `WM_ERASEBKGND` 返 1 不擦背景，而 `WM_PAINT` 只画 6px 轨道——圆钮与阴影凸出轨道上下的部分**从来无人重画**，快速拖动时旧位置抗锯齿残环逐帧累积成鬼影（缺陷自 v1.3.3 滑块诞生即潜伏，v1.3.10 上 AA 后更显眼）。修法：每帧先整块铺卡底 + 双缓冲（消闪烁）。**程序化压力测试证明**：120 次全行程往返（`TBM_SETPOS` 消息，非鼠标模拟）后 v1.3.12 有 119 种杂色/两个残环，v1.3.13 零残留。
- **摘要叠字（同类根因）**：`SumValProc` 画文字用 TRANSPARENT 模式且从不铺底，高频改文字时新字叠旧字。修法：SumVal/SumKey/Chip/StepNo 四处同类隐患统一绘制前铺父容器底色。
- **核验观察点 3 项（核实属实）**：①EN_CHANGE 条件刷新（custom 未勾选不每次敲键重扫目录）；②`on_browse_folder` 同理；③专属规则允许空图规则（对齐 Python `_adv_add`，Python 源码实证：只拦空路径）——去掉"请选择图片文件名"拦截，img 非空时保留存在性二次确认。

### v1.3.14 — 【重大】ini 写入链四 bug 根因修复（gdb 实锤）
用户实测：选自定义目录→点保存配置→卡死退出；config.ini 写烂（节名丢 `]`、键值丢失、中文注释变乱码、内容重复两遍）；DLL 报"缺少图片目录"；posType/imgAlpha 不生效。**全部同源**——`ini_write_value()` 文本重建链自 v1.3.0 起从未正确工作：
- **Bug A**：section 头就地截断取节名后把截断行写进输出→所有 `[section]` 丢 `]`，后续节识别全失效；
- **Bug B**：键行 `*eq=0` 截断比较后不恢复→同节内目标键之前的键全部丢 `=值`；
- **Bug C**：拼接缓冲 `malloc(32)` 字节配 `out_cap=32` 字符，ini 超 16 字符即**越界写堆**→砸坏堆元数据则保存崩溃，砸中相邻块则其它缓冲内容（日志字节 `04:25:49.323][pid=`）被拼进宽串写进 ini（乱码来源）；是否暴露全凭堆布局运气；
- **Bug D**：追加行尾 LF/CRLF 混排。
- A+B 叠加→节识别失效→每次保存把 7 键整组**追加**到文件尾（"内容重复两遍"）。另修 `mk_kv_line` 的 `%S` 按 ACP 转换致中文路径乱码（改显式 u8tow）；内嵌默认 config.ini 重制（folder 默认空、清历史 `\r\r` 群）。
- **验证创新**：gdb + 函数级 harness（无 UI 只跑 ini 链）先复现崩溃（`Heap block ... modified ... past requested size of 20`）再证明修复——不崩、原地替换、中文 UTF-8 正确。
